# HFPager-совместимый пейджер для macOS

Та же программа, что и для Windows (`hfpager_app.py`); отличаются только скрипты запуска.

## Запуск из исходников
1. Установите Python 3.10+ с python.org (в нём уже есть Tk). Версия из Homebrew требует
   `brew install python-tk`.
2. В Терминале: `cd` в папку программы, затем `chmod +x run_hfpager.command build_app.sh`.
3. `./run_hfpager.command` (или `python3 -m pip install --user -r requirements.txt` и `python3 hfpager_app.py`).
4. **Разрешите доступ к микрофону**: при первом запуске macOS спросит разрешение для Терминала
   (или для приложения). Если приём молчит: Системные настройки → Конфиденциальность и безопасность →
   Микрофон → включите Терминал / HFPagerApp.

## Собрать .app
`./build_app.sh` создаст `dist/HFPagerApp.app` (PyInstaller, нужен Mac и интернет). Приложение не
подписано сертификатом разработчика: при первом запуске – правый клик → «Открыть».

## Звук
В списках устройств выберите USB-аудиоинтерфейс трансивера (Core Audio). Входной и выходной
уровни настраиваются в «Настройки → Звук» и в «Аудио-MIDI настройке» (частота 48000 Гц).
Настройки и журнал: `~/Library/Application Support/HFPagerApp`.

Остальное (АПЧ, ограничения, что проверено) – как в `README_APP.md`. Я не мог запускать программу
на Mac: для macOS проверена только логика с имитацией звуковой карты и tkinter.
